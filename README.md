# Chatvardage — Application de clavardage

Projet scolaire réalisé en équipe dans le cadre de ma formation en Techniques de l’informatique.

## Présentation

Chatvardage est un projet d’application de communication comprenant une interface web, une application mobile et plusieurs services spécialisés. Son architecture répartit notamment l’authentification, les salons, les messages et la configuration des utilisateurs entre des services distincts.

## Fonctionnalités du projet

- Authentification et gestion des sessions.
- Gestion des salons et des invitations.
- Échange de messages.
- Affichage de la présence des utilisateurs lors des invitations.
- Interfaces web et mobile.
- Tableau de bord d’administration.
